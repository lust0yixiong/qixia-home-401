# 内置实拍材质来源

以下素材均来自 Poly Haven，采用 [CC0 1.0 授权](https://polyhaven.com/license)。文件随网页提供，访客无需连接外部素材服务。

| 网页名称 | 原始素材 |
| --- | --- |
| 自然橡木 | [Oak Veneer 01](https://polyhaven.com/a/oak_veneer_01) |
| 天然黑胡桃木 | [Black Walnut Veneer 01](https://polyhaven.com/a/black_walnut_veneer_01) |
| 米色大理石 | [Marble 01](https://polyhaven.com/a/marble_01) |
| 彩粒水磨石 | [Terrazzo Tiles](https://polyhaven.com/a/terrazzo_tiles) |
| 白色灰泥 | [White Stucco](https://polyhaven.com/a/white_stucco) |
| 格纹织物 | [Fabric Pattern 05](https://polyhaven.com/a/fabric_pattern_05)，配色 col_01 |

每种素材打包原始 1K JPEG 颜色、OpenGL 法线、粗糙度贴图，共 18 张。原始下载地址、大小和 MD5 记录在 [sources.json](sources.json)，与发布方清单逐一校验。颜色图使用 sRGB，法线与粗糙度使用线性数据；网页提供可调整的纹理重复与方向，未保证各模型面的纹理为实物 1:1 比例。

默认木饰面采用自然橡木。其余实拍材质可从“材质设置 → 浏览实拍材质”选择，首次使用时读取随站点打包的贴图。保留原有哑光烤漆、深色胡桃木、浅色石材、深灰岩板、拉丝金属五种基础预设，以兼容既有方案；这些细节图由 surface-finishes.js 生成。

用户本地上传的图片只存于浏览器，不会发送给 Poly Haven 或 GitHub。
