# 栖霞苑 · 空间漫游

基于 Three.js 的可交互三维户型，可浏览三维模型、设计效果图及施工图。

## 浏览

拖动旋转、滚轮缩放、右键平移。选择房间可快速定位；卫浴区支持高柜拉出与收回。

## 部署

纯静态网站，无需构建。GitHub Pages 发布源使用 `main` 分支的根目录。所有资源均为相对路径，支持项目子目录。

本地预览：在本目录运行 `python3 -m http.server 8765`，访问 `http://localhost:8765/`。

原设计图及模型仅供方案浏览，非施工精模。Three.js 的许可证见 `assets/THREE-LICENSE.txt`。

## 自定义材质

在三维空间中点击“材质设置”，选择材质分组，可调整颜色、贴图重复密度、方向和粗糙度。台面与黑色五金分别处理。支持上传不超过 10 MB 的 JPG、PNG、WebP；图片最长边自动优化至 2048 像素。

点击“点选换材质”，再点击模型上的墙面、柜体、台面等部件，会用橙色描边提示并打开材质面板，默认“仅此部件”。可切换“同类整体”统一搭配；整体编辑会覆盖该类部件的单独设置。“跟随同类材质”可撤销当前部件的独立设置。拖动仍可旋转，Esc 或“结束点选”退出选择模式。

素材与参数仅保存在当前浏览器的本地存储中，不会上传 GitHub，不影响其他访客。可导出包含贴图的 JSON 方案，换浏览器或分享后通过“导入方案”恢复。无痕模式或清理网站数据会清除本地保存。

方案包含各部件的独立材质，刷新可恢复，也可导入导出；兼容旧版按类别保存的方案。模型部件发生结构变化导致方案不匹配时，会保留当前方案并提示。透明玻璃、镜面及电器五金暂不支持点选换材质。


## 渲染质感与画质

三维视图左下角可选择“流畅 / 高画质”，自动记住选择。触屏设备默认流畅，其他支持的设备默认高画质。两档均保留环境反射、日光与局部灯光；高画质增加环境遮蔽接触阴影、较精细的阴影贴图和离屏抗锯齿。无法支持高画质的设备使用流畅模式。

六款实拍材质使用随站点打包的颜色、OpenGL 法线及粗糙度贴图；五款基础预设保留本地生成的细节贴图。柜门与台面等部件增加最多 3 mm 的内收倒角，保留外轮廓尺寸。灯带附近增加暖色局部照明。环境反射为通用室内光照，不等于实时镜面反射或光线追踪。

材质面板提供 13 种预设，其中六款实拍材质、两款新增石纹岩板外观预设可通过缩略图选择，另有五款基础预设；可继续调整颜色、粗糙度和金属感，适用于单个部件或同类整体。新增方案版本 3，兼容版本 1、2，包含预设、金属感和独立部件设置。预设素材已经打包在网站中，上传本地图片时会移除预设的凹凸与粗糙度贴图，避免不同纹理错配。

素材来源及授权见 [素材说明](assets/materials/ATTRIBUTION.md)。渲染扩展来自 Three.js r160，与现有引擎版本一致，使用已有 MIT 许可证。所有资源随网站提供，不依赖访客访问外部素材服务。

验证：`node --test tests/*.test.mjs`。

## 照片级路径追踪（v29）

在左下角「画质」选择「照片级 · 路径追踪」。右侧可切换四个室内机位、曝光、降噪和采样目标，选择 3840 像素即可预览并下载 4K 长边 PNG。画面比例跟随当前浏览窗口。拖动相机时先显示实时预览，静止 650 毫秒后重新累积；修改材质、上传贴图、改变灯光或抽拉柜位置会重建渲染快照。图片保存的是当前采样进度；128 为预览，512/2048 可继续改善噪点。照片级不作为刷新后的默认，防止打开网页就开始重负载计算。

- 路径追踪基于 MIT 授权 `three-gpu-pathtracer 0.0.20`、`three-mesh-bvh 0.7.3`，共享现有 Three.js r160。所有运行资源本地托管，无 CDN 依赖。`npm ci && npm run build:pathtracer` 可重新生成静态 bundle。
- 10 次漫反射/反射反弹、12 次透射遍历，镜面反射、玻璃折射和柔和降噪。原有材质编辑器的存储数据和部件 ID 保留，光学转换只作用于渲染快照。
- 室内取景补上 2.65 米的整体顶面以关闭原鸟瞰模型的顶部漏光；这是渲染围护，不代表已精确建模所有局部吊顶。回到普通视角会移除顶面。
- 灯位延续 P.04/P.07、分组延续 P.09。照片级使用逐灯光源而非实时预览的 12 灯合并池；软膜和线性灯带使用面光源。轨道灯模块数、光束、发光强度及约 3000 K 色温仍为展示假设，不是施工照度报告或厂商 IES 数据。
- 自然光采用程序化天空和原太阳方向，未加入室外建筑景观。普通视图的辅助环境光、补光和假窗外色板不参与路径追踪。
- 当前引擎不追踪原 `LineSegments` 地砖缝，也不将 bump 高度图自动转为位移；已有法线、粗糙度及颜色贴图参与着色。几何模型仍是按施工图重建的空间示意，布艺细节等尚不等同离线精模。
- WebGL2 和浮点渲染目标必需；引擎加载或着色器失败会保留照片级选择，显示明确的实时预览状态、具体错误和重试按钮；用户可手动返回高画质。照片级采用本地 GPU 渐进渲染，速度依显卡、画面尺寸和采样目标而变化。

床长沿东西方向，长边靠北墙、床头靠东墙，各留约 20 mm 示意安装缝；不再悬在房间中间。梯子位于西端的过道一侧，顶部和踏步全部在床垫外，解决旧模型两个梯杆穿出上铺的问题。下铺正面敞开，上铺留出与梯子对齐的入口。新增「次卧室 → 双层床近看」。床架总体尺寸来自厂商；安装缝、约 180 mm 梯子前伸、软护栏/床品和细部为展示近似。相邻衣柜、门洞和墙体位置不变；此项是替换展示床型，不代表原图纸标注了这个型号。

几何检查验证靠墙间距、床架外包和床垫尺寸、梯子不穿床垫、梯子至衣柜侧仍有超过 1.4 m 的模型净距，以及照片级快照属性有效。新床部件可继续点选换材质；未改动其他家具的几何和材质标识。

## 洗衣与淋浴共用门（v41）

按用户确认并对照 P.01、EL.07 及效果图 08，将洗衣区和淋浴区原有两扇独立门改为一扇共用转门。移除误建在转动范围内的固定隔墙及玻璃，保留左侧卫生间独立门。默认门扇关闭淋浴侧、露出洗衣入口；「卫浴与洗衣 → 门转到洗衣侧／淋浴侧」可切换两种位置，「洗衣入口近看」直接查看。

门高 2350 mm 沿用立面；平面门框和转轴按图转绘，转轴向右约 23 mm 避让现有洗衣柜，两侧门口等宽。此微调及门宽不是施工标注尺寸。历史门体在材质登记后隐藏，保留既有材质编号。几何检查覆盖两个入口的通断、单门扇数量、转入两区中间时的柜体净空，以及照片级几何有效性。
